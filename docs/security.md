# 安全、数据与恢复

## 默认边界

默认只监听回环地址。非本机使用前，配置 HTTPS、管理 Origin、可信反向代理和网络访问策略。Core 不信任 X-Forwarded-For，限流按照实际连接地址；代理下需要代理层配合限流，不能随意信任外部传来的转发头。

管理员密码用 Argon2id（随机 16 字节盐、32 MiB、2 轮）保存。随机会话仅在 Cookie 中，数据库保存摘要；12 小时过期。管理修改要求 CSRF，存在 Origin 时还验证管理 Origin。账号当前只有本地 admin 角色，无多租户或细粒度 RBAC。

初始密码不公开输出；随机生成时写数据目录 bootstrap-admin.txt（0600）。可在“系统状态”更改密码，新密码至少 12 字符；同时撤销其他登录会话。旧 bootstrap 文件不再能登录，建议用户自行安全移除。

注册令牌 10 分钟有效，只能 DELETE RETURNING 消费一次，注册和创建运行身份同一事务。运行凭据按 Agent 隔离，绑定单个项目；禁用、归档、暂停均阻止上报。撤销不可恢复，需创建新注册令牌并使用新状态目录注册。

## 采集安全

HTTP 请求体最多 256 KiB，每批最多 100 事件，单事件最多 8 KiB。字符串、属性数量、扁平值、事件类型、时间戳与项目身份都校验；未知字段拒绝。Core 生成 received_at/source_type/agent_id。事件按项目 ID 和 eventId 去重；UTC 日配额同事务更新，不因并发越过配额。限流表最多 10000 键、HTTP 工作槽最多 32 个；超载返回错误，不创建无界任务。

浏览器 Origin 白名单不是密钥。恶意非浏览器客户端可能伪造 Origin；入口仍由 IP 限流、项目配额、请求大小与事件校验约束。面向公开互联网前，应在部署层配置额外流量防护；当前版本没有行为风控和可信匿名用户认证。

SDK 可由 Nginx 自动注入，按站点同意配置启动，支持 DNT、显式停用与停止监听。点击自动记录元素类型、按钮名称、结构定位与所在区域，不需要业务提供埋点 ID；已有 data-tracelite-id 优先使用。按钮名称来自 aria-label、aria-labelledby、可见文字、按钮型 input 的 value、title 或图片 alt；不读取普通输入框的值，并排除被忽略、可编辑及隐藏的子节点。按钮名称和区域名称本身仍可能含个人信息，可通过 data-tracelite-ignore 或元素排除规则跳过。错误只记录类别。不要把账号、手机号等个人信息放进 data-tracelite-id。

Core 不存完整 IP、请求体、原始访问日志行或表单值。UA 用成熟解析库生成设备信息；品牌不可识别时为 Unknown。访问日志始终只产生 HTTP 请求，不能伪造点击和精确停留。

## 主机和 Docker

授权目录由本机参数决定，处理符号链接后检查目录边界；只读取普通文件。管理员应使用专用、不可被非受信任用户修改的日志目录，避免路径替换竞态。待发数据与凭据写入 0600 状态文件，所在目录 0700，单进程锁保护。不要把状态文件分享或提交。

Docker Socket 在 Agent 本机显式设置，属于高权限边界，即使客户端只使用 GET，持有 Socket 的进程本身仍需要受保护。发现与具体日志读取分开授权；日志必须还匹配完整 ID 白名单。当前源码没有 Docker POST/DELETE、exec、容器生命周期操作或远程 Shell API。

## 在线备份和恢复

“系统状态 → 下载数据库备份”使用 SQLite VACUUM INTO 生成一致性快照，下载后删除临时文件。备份含用户密码摘要、会话摘要、Agent 身份摘要与业务数据，需要保密。不可仅复制正在写入的主 db 文件作为完整备份。

恢复需由操作者明确执行：

1. 正常退出 Core；保存当前数据库及其 WAL/SHM，以便回退。
2. 用备份文件替换目标 TRACELITE_DB，权限设置为 0600，确认属于运行用户。
3. 不把旧 WAL/SHM 与恢复后的新数据库混用；在 Core 已停止的前提下移走旧附属文件。
4. 启动 Core，查看健康和数据。恢复旧备份可能使较新的 Agent 身份失效，需要重新注册。

此流程未自动执行，也没有删除任何现有数据。灾难恢复和异常断电场景需在隔离数据副本中进一步演练。

## 保留与限制

每小时清理项目过期事件，保留配置最近 20 版、Agent 错误最近 2000 条、审计最近 10000 条，过期管理员/注册令牌也清理。清理不意味着立即缩小 SQLite 文件；已释放页将复用。

磁盘满、超高流量、长期运行、代理环境、Linux 文件权限和 SQLite Busy 仍需专项验收。当前不是宣称已完成安全审计的正式发布版。
