# 当前交付状态

2026-11-20，本机开发版本 0.1.0-dev。以下区分源码实现、自动测试与实机验收，不把它们合并成“已全部验证”。

## 已实现

- Go Core、Go Host Agent、Browser SDK、React 后台的 Monorepo。
- 实际可执行的 make setup/dev/agent/test/check/build/site/docker-test。
- Core、Web 和 SDK 开发编排，Go 自动重启与前端热更新；Host Agent 可独立或统一编排。
- SQLite WAL，启动迁移、持久化、数据保留清理、一致性在线备份。
- 随机初始化管理员、Argon2id、会话认证、CSRF、改密码与审计。
- 项目新增/编辑/暂停/归档、Origin、浏览器采集策略及版本回滚、保留期与写入配额、名称确认后删除项目数据。
- Agent 单次注册、独立凭据、心跳、在线/离线/警告/禁用状态、配置版本及回滚载入、运行指标、错误日志、禁用、撤销与名称确认后删除管理记录。
- 多种访问日志适配器、目录授权、偏移、inode 轮转检测、持久化有界队列、断线重试和事件去重。
- 真实事件、统计、路径、UA 设备分类、浏览器与 OS、匿名会话及分页时间线。
- Browser 自动页面、SPA 路由、受限点击、页面隐藏停留、异常类别、基础性能、DNT/同意后初始化/停止采集。
- Docker 本机 Socket 只读容器发现、逐容器本机授权、Host Collector 日志读取与配置关联。
- 本机验证站点，主动操作产生真实 Browser 事件，实际 HTTP 请求写结构化访问日志。

## 已自动验证

详细命令与结果见 testing.md。测试调用真实 Core Handler、SQLite、Host Agent 和日志解析逻辑；HTTP 测试传输不启动端口，不访问 UI。不使用 Mock API 替换产品功能。测试数据仅在临时目录，绝不写入用户开发数据库。

## 尚未实机验收

- 用户主动运行 make dev 后的交互与视觉检查；没有打开浏览器或进行界面验收。
- make build 的完整产物验证：遵守用户偏好，未自动运行生产构建。
- 当前环境没有 Docker CLI/已配置的 Socket；Docker 实机测试跳过，没有任何容器被修改、停止或删除。
- React/Vue/原生站点的真实浏览器兼容性矩阵，SDK 生命周期已有内存 DOM 测试，真实浏览器仍需验收。
- Linux 2GB 目标机性能、RSS、磁盘压力、长时间运行、SQLite Busy、异常退出恢复专项。

## 当前能力边界 / 后续功能

这些尚未实现，不能当成正式 V1 全部完成：

- 安装器、跨架构产物、systemd、升级回滚、卸载和正式发布脚本：明确延期。
- Docker Sidecar 创建/停止/清理、远程受控部署：当前用 Host Collector，不执行容器生命周期操作。
- 代理自动注入、代理配置备份与回滚：当前手动接入 SDK。
- 多用户细粒度 RBAC、项目异步清理任务、远程卸载/升级。
- UA 品牌和 Android 平板更细分类、原始 UA 可选保留、独立设备型号统计及设备趋势。
- 热门来源/自定义事件排名、预聚合表和大数据量查询优化、长期容量趋势告警。
- 轮转前旧文件未读尾部跟进、copytruncate 同 inode 快速恢复的完善处理。
- Docker 单次返回超过 256 KiB 时当前报告错误并暂停该轮读取，尚未实现大积压流分页；不静默截掉积压。
- SSE 实时状态、强制立即健康探测，当前依赖 30 秒心跳和手动刷新。

正式打包的闸门保持关闭，直到主要功能与安全/持久化、Docker 和目标环境验收通过。原始 PRD 中超出此版本的要求仍有效，未被删除。
