## 当前本机模式的使用路径

1. make dev → 读取实际数据目录的 bootstrap-admin.txt → 登录。
2. 进入「探针管理 → 站点接入」，等待自动扫描；查看预览后点击「确认接入」。无需先创建项目或注册远程 Agent。
3. 访问原业务网址。对外站点按配置提供同意信号；收到首批有效事件后，站点出现在左侧列表。
4. 在站点页查看页面、点击聚合、事件、设备和访问轨迹；在「探针管理 → 探针管理」查看本机探针健康与心跳。
5. 在「系统设置 → 运行设置」修改密码或下载备份，在「安全审计」查看异常、配额及审计记录。
6. make site 启动仓库中的验证站点，供手动查看兼容模式下的 SDK 接入流程。
