# 本机手动验收流程

1. 运行 `make dev`。使用首次启动前配置的管理员凭据，或读取实际数据库目录下的 `bootstrap-admin.txt` 登录。
2. 打开「探针管理 → 站点接入 → 添加站点 → 一键扫描」，点击「扫描站点」。查看预览后勾选并点击「接入并启用」。手动添加站点时，保存后在站点接入表开启采集。
3. 在站点列表选中已启用站点，确认无数据时显示「等待首批数据」。访问原业务网址，并按站点配置提供同意信号。检查最近上报及对应的页面、点击、事件、设备和访问轨迹。
4. 在「探针管理 → 探针管理」查看探针健康与心跳，在「站点接入」查看 SDK 状态。暂停采集后检查新数据是否停止入库。
5. 在「系统信息」查看统计时区、软件更新和更新日志，在「运行设置」修改密码或下载备份，在「安全审计」查看运行异常、写入配额及审计记录。

没有可用的业务站点时，可先用 `make site` 启动示例网站，默认上游为 `http://127.0.0.1:5174`，再按接入指南的「启动独立的本地测试入口」配置 Nginx，把上游改为该地址。通过 Nginx 入口访问示例页面，使用同源注入验证采集。 [本地测试入口](host-nginx.md#可选启动独立的本地测试入口)
